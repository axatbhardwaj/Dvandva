# Domain Docs

This repository uses a single domain context.

Before exploring or changing the system:

1. Read the root `CONTEXT.md`.
2. Read applicable decisions under `docs/adr/`.
3. Use the glossary's defined vocabulary rather than introducing synonyms.
4. Surface conflicts with accepted ADRs instead of silently overriding them.
5. If a required term is absent, record the gap for domain modeling rather than inventing an implicit definition.

Missing optional domain documents should not block normal exploration.
