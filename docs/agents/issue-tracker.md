# Issue tracker: GitHub

Issues and specifications live in GitHub Issues for `axatbhardwaj/Dvandva`. Use the `gh` CLI for tracker operations.

## Conventions

- Create issues with `gh issue create`.
- Read issues and their comments with `gh issue view`.
- Publish updates with `gh issue comment`.
- Apply or remove labels with `gh issue edit`.
- Close completed or rejected issues with `gh issue close`.
- Infer the repository from the current Git remote.
- Pull requests are not a request or triage surface.
- When a skill says to publish to the issue tracker, create a GitHub issue.
- When a skill says to fetch a ticket, read the corresponding GitHub issue and its comments.
