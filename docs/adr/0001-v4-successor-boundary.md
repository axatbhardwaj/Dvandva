# Develop v4 beside the frozen v3 archive

Dvandva v4 is developed in a separate, non-publishable `v4/` subtree while
the `v3.5.1` crate, plugin source, historical docs, release, and Pages artifact
remain frozen. This preserves the retirement record and its distribution
guards while allowing a smaller T3-native successor whose Claude and Codex
sessions communicate only through durable run state; activation, installation,
source publication, release, and GitHub unarchiving remain separate decisions.
