# Dvandva skills 0.4.2

- Make every active HTML explainer answer the human questions first: what the
  result is, why it matters, what the current status is, and what happens next.
- Keep dense protocol evidence available through progressive disclosure while
  requiring plain-language summaries, explicit ownership, and actionable next
  steps in the first viewport.
- Strengthen the standalone validator and regression suite so answer-first
  placement, substantive content, and explicit status/action answers cannot
  silently regress.
- Preserve the shared visual system, accessibility behavior, owner-only Sites
  publication, and immutable evidence receipts.

The private kernel is version 0.4.2; run schema `dvandva.run.v2` and role API 2
are unchanged. This release targets Linux x86_64. Update the four active skills
and run setup-dvandva to install the matching private kernel.
